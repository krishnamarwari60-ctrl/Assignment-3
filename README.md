# Assignment- 3 DATA ANALYSIS WITH SQL
 
 
## Introduction
This internship assignment focuses on utilizing SQL for data analysis tasks. The goal is to provide hands-on experience with querying databases, manipulating data, and generating insights from datasets.

## Assignment Objectives
- Understand the basics of SQL and relational databases.
- Perform data retrieval and manipulation using SQL queries.
- Gain experience in JOIN operations, subqueries, and data aggregation.
- Analyze datasets to derive meaningful insights and present findings.
